# OverWatch

A live exchange on London's next five minutes: trade whether parts of the city get busier or quieter, settled on real
TfL readings, against AI market makers, hedge funds and retail traders. Built at WHACK 26.

Code: https://github.com/chocoliticekreem/whack. This Space builds `main` from GitHub; see that repo's README,
"Free public site", for how it runs.
